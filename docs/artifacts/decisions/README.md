# Decision Records

Use this folder for durable decisions.

A decision record is required when work creates or changes:

- architecture direction
- dependency policy
- product behavior
- compatibility promise
- testing standard
- workflow rule
- do-not-touch area

Do not bury real decisions in chat or session memory only.
