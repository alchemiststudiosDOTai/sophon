# Active Artifacts

This folder contains current work.

Keep only active charters and execution logs here.

When work is finished:

- evidence goes to `docs/artifacts/evidence/`
- session memory goes to `docs/artifacts/memory/`
- decisions go to `docs/artifacts/decisions/`
- unresolved issues go to `docs/artifacts/open-issues/`

Move completed charters/logs to `docs/artifacts/completed/` or mark them Completed and link the Session Memory.
