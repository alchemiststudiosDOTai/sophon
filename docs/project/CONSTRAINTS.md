## Hard Constraints

| Constraint | Reason | Source / Evidence |
|---|---|---|
| No Charter = No Code for execution work. | Keeps scope, constraints, and proof explicit before edits. | `docs/process/RULES.md`, `AGENTS.md` |
| No Evidence = No Done. | Prevents unsupported completion claims. | `docs/process/RULES.md`, `docs/artifacts/INDEX.md` |
| Durable decisions require a Decision Record. | Avoids hidden constraints and stale chat-only decisions. | `docs/process/RULES.md` |

## Architecture Constraints

| Constraint | Reason | Source / Evidence |
|---|---|---|
| `src/domain/` must not import providers, transport, CLI, or app layers. | Keeps domain provider-agnostic and pure. | `tests/architecture_test.rs` |
| `src/transport/` must not import providers, CLI, or app layers. | Keeps transport reusable below adapters. | `tests/architecture_test.rs` |
| `src/providers/` must not import CLI or app layers. | Keeps provider adapters behind domain contracts. | `tests/architecture_test.rs` |
| `src/app/` must not import CLI, bootstrap, providers, or transport. | Keeps orchestration dependent on domain contracts only. | `tests/architecture_test.rs` |
| `src/bootstrap/` must not import CLI. | Keeps service construction separate from user input parsing. | `tests/architecture_test.rs` |
| `render_text` belongs only in the CLI layer. | Prevents presentation concerns from leaking into domain/app code. | `tests/architecture_test.rs` |

## Dependency Constraints

| Constraint | Reason | Source / Evidence |
|---|---|---|
| Rust edition is 2024. | Current crate configuration. | `Cargo.toml` |
| New dependencies must be added through `Cargo.toml` and validated by `just check`. | Keeps dependency changes explicit and tested. | `Cargo.toml`, `justfile` |
| `cargo +nightly udeps` is part of hygiene, not the main check gate. | `cargo-udeps` relies on nightly internals. | `justfile`, `HARNESS.md` |

## Compatibility Constraints

| Constraint | Reason | Source / Evidence |
|---|---|---|
| Windows PowerShell should run `just --shell powershell --shell-arg -Command check`. | Plain `just check` may look for `sh`. | `AGENTS.md` |
| CLI results stay on stdout and logs stay on stderr. | Keeps output scriptable. | `AGENTS.md`, existing tracing setup |
| Live provider calls require environment API keys. | Avoids assuming local secrets. | `README.md` |

## Style / Taste Constraints

| Constraint | Reason | Source / Evidence |
|---|---|---|
| Keep docs concise and link to deeper sources of truth. | Prevents duplicated stale instructions. | `AGENTS.md`, `docs/process/RULES.md` |
| New tracked Markdown needs YAML frontmatter with ontology relations. | Required by the docs metadata gate. | `scripts/check_markdown_frontmatter.py`, `HARNESS.md` |
| Do not commit `.DS_Store` or generated build output. | Prevents machine-local and generated noise. | `.gitignore`, `AGENTS.md` |

## Do-Not-Touch Areas

| Area | Reason | Owner / Source |
|---|---|---|
| `.env` and real API keys | Secrets must stay local. | Maintainers / `.gitignore` |
| `target/` and `book/` generated output | Regenerated by local commands and ignored. | `justfile`, `.gitignore` |
| `.artifacts/` local scratch artifacts | Ignored local agent scratch space; repo control plane lives in `docs/artifacts/`. | `.gitignore`, `docs/artifacts/INDEX.md` |
